# 🎓 Semester X

> **A student-first platform designed to make semester preparation simpler, smarter, and more organized.**

Semester X is an academic platform developed to help college students prepare efficiently for their semester examinations. It brings together essential study resources such as notes, previous year question papers, syllabi, short notes, and more in a clean, organized, and user-friendly environment.

Rather than making students search across multiple websites, Telegram groups, and shared drives, Semester X aims to become a single, reliable destination for academic preparation.

> 🚧 **This collaborative project is currently under active development.**

---

# 🤔 Why Semester X?

Many platforms already provide study materials, but most focus only on sharing PDFs and often rely heavily on advertisements or poorly organized content.

Semester X takes a different approach.

* 📚 Everything in one organized platform.
* 🚫 A student-first experience with minimal, non-intrusive advertisements.
* ⚡ Fast, clean, and distraction-free interface.
* 👨‍🎓 Built by students who understand the real challenges of semester preparation.
* 🚀 Designed to grow into a complete academic ecosystem with AI-powered learning tools, study planning, progress tracking, and more.

**Our goal is simple:** let students spend more time studying and less time searching.

# 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/<your-username>/Semester-X.git
```

### Frontend

Open the frontend using Live Server or any local web server.

### Backend

```bash
cd backend
mvn spring-boot:run
```

Configure your MySQL database and update the credentials in `application.properties` before running the server.
